# Pharmacy Management System (Access Project)

This is a database management system for a pharmacy, built using Microsoft Access.

## 👥 Team Roles & Contributions
* **Abanoub Bassem:** UI/UX Design (Designed user forms, customized reports, color coordination, visual layout, and interface alignment).
* **Team Members:** Database backend, queries, and logic implementation.

## 🎨 UI/UX Features
* Clean and structured forms for managing **Customers**, **Medicines**, **Sales**, and **Suppliers**.
* Professional color coding and organized layout for easy data entry and navigation.
* Customized reports (`customers report`, `medicines report`) optimized for clean printing and viewing.
